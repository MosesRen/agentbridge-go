# Code of conduct / 行为准则

## English

Be respectful, constructive, and specific. Critique code and ideas, not people. Harassment, discrimination, threats, doxxing, and unwanted sexual attention are not acceptable. Respect privacy and do not publish another person's private information.

These expectations apply to project issues, pull requests, reviews, and other project spaces. Maintainers may edit/remove inappropriate content, close discussions, or restrict participation, taking severity and repeated behavior into account.

To request moderation, contact the [maintainer](https://github.com/MosesRen) through an available private channel. If none is available, open a minimal moderation request in the issue tracker without personal or sensitive details. Use [SECURITY](SECURITY.md) for security vulnerabilities. Maintainers are expected to follow these same standards.

## 中文

尊重他人，讨论具体问题，提供建设性反馈。评价代码和观点，不攻击个人。不接受骚扰、歧视、威胁、人肉搜索或不受欢迎的性关注。尊重隐私，不公开他人的私人信息。

准则适用于项目 Issue、PR、评审和其他项目交流空间。维护者可按严重程度和重复情况编辑/删除不当内容、关闭讨论或限制参与。

需要处理不当行为时，通过可用的私密渠道联系[维护者](https://github.com/MosesRen)。没有私密渠道时，可在 Issue 中简要请求介入，不附个人或敏感细节。安全漏洞按[安全政策](SECURITY.md)处理。维护者同样应遵守以上准则。
