# Security policy / 安全政策

## English

This project is in pre-release development. Fixes target the current `main` branch; there is no long-term-support or guaranteed response-time commitment.

For a suspected vulnerability, use the repository's [Security page](https://github.com/MosesRen/agentbridge-go/security). If **Report a vulnerability** is available, submit a private report there. This document does not imply that GitHub private reporting is enabled.

If no private reporting option is available, open an issue requesting a private contact channel **without exploit details, credentials, private transcripts, or sensitive paths**. Wait for a maintainer to arrange a private channel before sharing those details.

A private report should describe the affected commit/module and platform, impact, and a minimal reproducer. Ordinary bugs can use the public issue tracker. Issues in Claude Code, model services, or upstream dependencies should also be reported to the relevant upstream maintainer.

## 中文

项目处于发布前阶段。安全修复针对当前 `main` 分支，暂不承诺长期支持或固定响应时限。

发现疑似漏洞时，先查看仓库的 [Security 页面](https://github.com/MosesRen/agentbridge-go/security)。如果显示 **Report a vulnerability**，通过该入口私密提交。本文不表示 GitHub 私密报告功能已经启用。

如果没有私密入口，可以先开 Issue 请求私密联系方式，**不要附带利用细节、凭据、私人会话或敏感路径**。等待维护者安排私密渠道后再提供详细信息。

私密报告应说明受影响的提交/模块、平台、影响和最小复现。普通缺陷使用公开 Issue；Claude Code、模型服务或上游依赖的问题也应反馈给相应维护者。
